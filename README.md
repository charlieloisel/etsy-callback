# NolaroPrints Etsy Tool
A personal-use tool for managing my own Etsy shop, [NolaroPrints](https://www.etsy.com/uk/shop/NolaroPrints).
## What this is
This is a small personal automation I built to help create digital-download listing drafts (printable wall art) for my own Etsy shop. I am the sole owner of the shop and the sole user of this tool.
This repo also hosts the OAuth callback page used during the authorization flow.
## What it does
- Creates **draft** (unpublished) listings in my own shop via the Etsy Open API v3
- Uploads digital product files and preview images to those drafts
- Reads my own
shop's listing status
It does **not** publish anything automatically - every listing is reviewed and published by me personally through the Etsy website before it goes live.
## What this is not
- Not a service offered to other sellers
- Not multi-tenant or multi-shop
- Not resold, distributed, or shared with any third party
